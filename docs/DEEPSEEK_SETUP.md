# DeepSeek API 集成指南

本文档说明如何配置和使用 OA-Tools 中的 DeepSeek AI 生成工具（图片/视频生成）。

## 📋 前置要求

- 已获得 DeepSeek 平台的 API Key
- 已创建 DeepSeek 账户：https://platform.deepseek.com/
- 已配置相应的 API 额度

## 🔧 配置步骤

### 1. 获取 DeepSeek API Key

1. 访问 [DeepSeek 开放平台](https://platform.deepseek.com/)
2. 使用邮箱注册或登录账户
3. 进入开发者后台，查找 "API Keys" 或 "密钥管理" 菜单
4. 创建新的 API Key（如果还没有）
5. 复制 API Key（通常格式为 `sk_xxx`）

### 2. 配置环境变量

#### 方式一：在系统环境变量中配置（推荐）

**Windows:**
1. 按下 `Win + R`，输入 `sysdm.cpl`
2. 点击"环境变量"按钮
3. 新建系统变量：
   - 变量名：`DEEPSEEK_API_KEY`
   - 变量值：`你的API密钥`
4. 点击确定，重启命令行/编辑器

**Linux/Mac:**
```bash
# 在 ~/.bashrc 或 ~/.zshrc 中添加
export DEEPSEEK_API_KEY=sk_your_api_key_here

# 然后执行
source ~/.bashrc
# 或
source ~/.zshrc
```

#### 方式二：在 `.env` 文件中配置（开发用）

1. 在项目根目录创建 `.env` 文件（如果不存在）
2. 添加以下内容：
```env
DEEPSEEK_API_KEY=sk_your_api_key_here
DEEPSEEK_IMAGES_API_URL=https://api.deepseek.com/v1/images/generations
DEEPSEEK_VIDEOS_API_URL=https://api.deepseek.com/v1/videos/generations
```

3. **重要：** 不要将 `.env` 文件提交到 Git
   - 确保 `.gitignore` 包含 `.env` 条目

### 3. 重启应用

配置环境变量后，需要重启后端服务：

```bash
# 停止当前服务
npm run stop

# 重新启动
npm run dev
```

## 🎨 使用指南

### 图片生成

1. 打开 OA-Tools 应用
2. 导航到 **工具 → 图片/视频转换**
3. 点击 **图片生成** 标签页
4. 填写参数：
   - **图片描述**：输入详细的图片描述文字（中文或英文）
   - **模型**：选择 DeepSeek Vision 或 Vision Pro
   - **分辨率**：选择 512x512、768x768、1024x1024 等
   - **质量**：Standard（标清）、HD（高清）、Ultra（超清）
   - **风格**：自然、油画、卡通、摄影、动画、概念艺术等

5. 点击 **🎨 生成图片** 按钮
6. 等待图片生成完成
7. 点击 **⬇️ 下载图片** 下载生成的图片

### 视频生成

1. 导航到 **工具 → 图片/视频转换**
2. 点击 **视频生成** 标签页
3. 填写参数：
   - **视频描述**：输入详细的视频描述文字
   - **模型**：选择 DeepSeek Video 或 Video Pro
   - **时长**：1-10 秒（滑块调整）
   - **帧率**：24/30/60 FPS
   - **分辨率**：720p、1080p、2K、4K
   - **质量**：Standard、HD、Ultra

4. 点击 **🎬 生成视频** 按钮
5. 等待视频生成提交
6. 监控生成状态（某些模型上通常需要更长时间）
7. 完成后点击 **⬇️ 下载视频**

## 📝 提示词最佳实践

### 图片提示词示例

**好的提示词：**
```
一只可爱的橘猫坐在书籍堆上，窗户透进柔和的阳光，被毛蓬松，眼睛翠绿色，
背景是现代书房，氛围温暖舒适，插画风格，高清8K质量
```

**不够好的提示词：**
```
猫咪
```

### 视频提示词示例

**好的提示词：**
```
机器人行走在未来城市街道上，高楼大厦，霓虹灯光闪烁，
飞行汽车在空中穿梭，夜幕降临，科幻电影风格，4K质量，平滑运动
```

### 提示词编写建议

1. **具体描述对象**：不要写"一个东西"，要写"一只橙色的土耳其安哥拉猫"
2. **描述场景/背景**：增加背景信息使图像更丰富
3. **指定风格**：插画风格、油画、摄影、动画、概念艺术等
4. **指定角度/视角**：俯视图、侧面、特写等
5. **使用颜色**：指代具体的颜色而不是"彩色"
6. **指定质量/分辨率**：高清、8K、高清晰度等
7. **使用情感词**：温暖、黑暗、活力、平静等

## ⚙️ 高级配置

### 自定义 API 端点

如果使用的是自托管或代理的 DeepSeek API，可以自定义端点：

```env
DEEPSEEK_API_URL=https://your-proxy.com/v1/images/generations
```

### 请求超时配置

默认超时时间：
- 图片生成：60 秒
- 视频生成：120 秒

可在 `client/src/api/tools.js` 中的请求函数中调整 `timeout` 参数。

## 🐛 常见问题

### 问题 1：API Key 未被识别

**症状：** 收到 "DeepSeek API Key 未配置" 错误

**解决方案：**
1. 检查环境变量是否正确配置
2. 确认 API Key 格式正确（应以 `sk_` 开头）
3. 如使用 `.env` 文件，确保服务已重启
4. 检查 `.env` 文件是否在项目根目录

### 问题 2：请求超时

**症状：** 生成超过 60 秒后报错超时

**解决方案：**
1. 增加请求超时时间（见高级配置）
2. 检查网络连接
3. 尝试降低分辨率或质量
4. 检查 DeepSeek API 服务状态

### 问题 3：生成失败，错误信息为 "Insufficient quota"

**症状：** 提示余额不足或配额用尽

**解决方案：**
1. 登录 DeepSeek 平台检查余额
2. 充值或升级账户
3. 降低生成分辨率或质量以节省成本

### 问题 4：生成的图片/视频质量不好

**解决方案：**
1. 改进提示词（参考"提示词最佳实践"）
2. 提高质量设置（Standart → HD → Ultra）
3. 提高分辨率
4. 尝试不同的风格
5. 多次尝试（AI 生成具有一定随机性）

### 问题 5：网络连接问题

**症状：** 无法连接到 DeepSeek API

**解决方案：**
1. 检查网络连接是否正常
2. 检查是否配置了代理或防火墙
3. 尝试使用 VPN（如在某些地区访问有限制）
4. 检查 API 端点 URL 是否正确

## 🔐 安全建议

1. **不要在代码中硬编码 API Key**
2. **不要将 `.env` 文件上传到 Git**
3. **定期更换 API Key**
4. **监控 API 使用情况，防止滥用**
5. **使用环境变量而不是配置文件**
6. **限制 API Key 的权限范围**
